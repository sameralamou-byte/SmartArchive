1. Production method

Decision: one method for all five assets

AI image generation with a locked reference workflow — not stock libraries, not a physical photoshoot for v1.

Why AI (not stock, not shoot)

  • Protagonist lock: Stock cannot guarantee the same adult as Page 1 hero (green sweater, face, desk continuity). A photoshoot could, but cost/scheduling blocks the one-pass §3–§8 timeline.
  • Fictional documents: AI can keep letter text soft-focus / illegible and avoid real seals; stock “official letter” packs often include real-looking authority cues we must reject.
  • Consistency across five frames: One reference image + fixed prompt block + same tool/model family is the practical way to keep face, wardrobe, wood, and light direction aligned when shots are generated separately.
  • Page 1 already set the bar with AI-assisted editorial stills in the approved hero look; Page 2 should match that production path, not invent a second visual economy.

Exact workflow (all five shots)

  1. Reference (fixed): Always attach / img2img against frontend/public/assets/page1/page1_hero_human_document.png as identity + wardrobe + desk + light reference — even for hands-only and still-life shots (desk wood / mug / lamp continuity).
  2. Tool: Cursor native image generation (GenerateImage) or the same ChatGPT/Image model family already used for Page 1 marketing stills — pick one tool for the whole batch and do not mix Midjourney/other for Page 2.
  3. Shared prompt stem (paste into every generation): Same adult man as reference: short dark hair, light stubble, dark forest-green crew sweater, calm focused expression, warm home desk, wood table, soft lamp, soft-bokeh books and plant, warm natural side light, cream–petrol–gold props. Photoreal editorial, shallow depth of field. Fictional documents only — Example Administration / Amt für Beispiele / Example City. No real government seals, no readable personal data, no UI chrome, no app screens, no logos, no holograms, no robots.
    Negative prompt (all five shots): No real government, authority, or institution names as legible text — fictional only (Example Administration / Amt für Beispiele / Example City). If any generated text is legible enough to read a name, it must be one of the approved fictional names, not a real one.
  4. Per-shot delta: Only the framing line from §2 below (closer crop / quiet offer / tabletop / prep / reminder).
  5. Consistency check before file accept: Side-by-side with Page 1 hero — same person, same sweater color family, same desk wood tone, same light direction (warm key from viewer’s left/upper). Reject and regenerate if face or wardrobe drifts.
  6. Export: PNG, sRGB, no baked text overlays, no SmartArchive UI. Deliver at or above minimum source resolution in Part 3.
  7. Name and place: Exact filenames in Part 2 under frontend/public/assets/page2/ — only during the eventual one-pass implementation (not now).
If AI consistency fails after 2–3 regenerations on one slot

Escalate that single slot to a short controlled photoshoot (same wardrobe + desk setup), still using the bible. Do not silently fall back to stock faces. Do not reopen the photography bible.
