Hard visual rules (stop the loop)

  • No 2×3 / diamond / chip feature catalogue for capabilities.
  • No repeating the full Example Administration letter as a card in every section.
  • No universal grey SceneFrame wrapping every section.
  • No mixing real photography and illustrative SVG inside the same section’s primary visual.
  • Gold (--accent-2) = what matters (dates, decisions). Teal/petrol = understanding / Weave. Coral (--accent) = CTAs / actions only — never “important date” text.
  • Each section must be a different visual moment, not the same layout with new labels.

§3–§8 as one set (the proposal)

§3 Quiet offer — One dark petrol band. Primary: a still photograph of the same desk/document world from §2, slightly wider (person or hands reviewing). Assistance options appear as quiet caption labels under the photo (Understand / Translate / … with Demo or Concept tags), never as a geometric diamond or equal cards. Funnel below: SmartArchive can help → User review → large gold “Your decision” block. Ends the help story in control.

§4 Situations — Recessed sage “tabletop.” Ghost envelopes in the background. Primary: one selected envelope/document situation (Immigration etc.). Tabs stay functional but visually secondary (low-contrast pills). Two editorial columns: understands (Demo) / possible help (Concept). Legal line unchanged.

§5 Translation ≠ Understanding — No photography. Three ascending stages of the same fictional sentence: Original → Translation → What it means. Visual weight increases left→right (or top→bottom on mobile). Final stage uses gold border / cream tint. Keep the phrase “Translation ≠ Understanding.”

§6 Preparation — Photograph of physical prep (checklist papers, form, pen — fictional). Beside or below: requirements list → steps → closing line “You review. You decide. You send.” Concept tag stays. No dashboard checklist UI chrome.

§7 Reminder — Photograph of one calm date moment (hands + calendar slip or phone with fictional “31 October / Example Administration”). Gold as the only urgency signal. Sequence: document → date → reminder → user decision. No red alarms.

§8 Connected history — Pure Weave: horizontal node/edge story on desktop (Original → … → Outcome), vertical on mobile. Teal connections. Concept tag. No photo, no card stack.

2. Relation to “A Closer Look” (Claude blueprint)

Treated as the starting reference. File was not found as a separate repo document; content recovered from the session blueprint (“A CLOSER LOOK” continuous-attention narrative). Ask Samer if a standalone file should be filed under design/page2/.

Where this proposal follows the blueprint
  • One narrative, not seven SaaS modules.
  • §3 is a quiet offer ending in user decision — not a feature grid.
  • §4 is editorial situation, not a database table.
  • §5 emphasizes “what it means” over translation.
  • §6 physical preparation + user responsibility.
  • §7 calm single-date reminder; gold, not alarm red.
  • §8 Weave as connected story, horizontal on desktop.
  • Honesty labels and copy keys stay as-is.
Where this proposal diverges — and why
  • §3 “whisper diamond” layout rejected. Absolute-positioned whispers around a teal diamond produced the stray rectangle / overlap loop. Replace with: photo primary + soft caption row under it + funnel. Same meaning, fewer collision surfaces.
  • Photography is mandatory for human sections, forbidden for abstract ones. The blueprint allowed annotation/typography-only richness; Page 1 proved photography is the quality bar. Explicit photo-vs-SVG split prevents another “swap the photo mid-pass” inconsistency.
  • §2 stays photographic editorial (current intent) but must use the locked protagonist bible below — not ad-hoc Page 1 asset copies with baked UI.
  • Hero remains the approved UI document scene (not replaced with photography). Wide glance = UI mock; closer look = photo. That contrast is intentional, not a defect.

3. Photography bible — one protagonist system

Locked subject (resolve today’s inconsistency)

Face when shown: Same adult as Page 1 hero (page1_hero_human_document.png) — short dark hair, light stubble, dark forest-green crew sweater, calm focused expression, home desk.
Hands-only crops: Must read as the same person (skin tone, wardrobe edge if visible, same desk wood, same warm side light).
Never: swap to a different face mid-Page-2, or reuse page1_understand_hands_document.png for Page 2 (baked “Understand / Learn how” UI).

Setting / wardrobe / mood (apply everywhere a photo is used)

  • Setting: Warm home desk — wood table, soft lamp, books/plant soft-bokeh. Not office glass, not neon AI lab.
  • Wardrobe: Forest-green sweater (or matching knit). No logos, no uniforms.
  • Mood: Calm attention, slight concern — never panic, never “tech bro,” never stock smile.
  • Light: Warm natural / lamp; cream–petrol–gold palette in props.
  • Documents in frame: Always fictional — “Example Administration,” “Amt für Beispiele,” “Example City.” No real seals, authorities, case numbers, or identifiable PII. Text on paper may be soft-focus / illegible if needed.
