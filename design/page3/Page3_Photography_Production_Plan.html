Decision

Exact workflow (one shot)

  1. Reference (fixed): Attach / img2img against frontend/public/assets/page1/page1_hero_human_document.png as identity + wardrobe + desk + light reference.
  2. Tool: Cursor GenerateImage or the same ChatGPT/Image family used for Page 1/2 stills — pick one; do not mix Midjourney/other for Page 3.
  3. Shared prompt stem: Same adult man as reference: short dark hair, light stubble, dark forest-green crew sweater, calm focused expression, warm home desk, wood table, soft lamp, soft-bokeh books and plant, warm natural side light, cream–petrol–gold props. Photoreal editorial, shallow depth of field. Quiet stewardship mood — private archive, not deadline urgency. Fictional documents only — Example Administration / Amt für Beispiele / Example City. No real government seals, no readable personal data, no UI chrome, no app screens, no logos, no holograms, no robots, no padlocks, no shields, no server racks, no cyber grids.
    Negative prompt: No real government, authority, or institution names as legible text — fictional only (Example Administration / Amt für Beispiele / Example City).   4. Per-shot delta: Hero framing line in §3 below only.
